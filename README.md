# Kit Marmita Lucrativa

Landing page oficial do Kit Marmita Lucrativa, um produto digital composto por guia em PDF e planilha editável para quem deseja organizar uma operação de venda de marmitas.

## Publicação

Projeto estático preparado para publicação automática na Vercel.

## Checkout

Os botões de compra direcionam para o checkout oficial da Kiwify.
